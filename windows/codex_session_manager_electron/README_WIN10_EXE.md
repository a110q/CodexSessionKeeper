# codex_会话管理 Windows 10 免安装版

这是 Windows 10 x64 免安装 exe 版本。解压后双击：

```text
codex_session_manager.exe
```

不要只拷贝单独的 exe 文件，Electron 运行时需要旁边的 `resources`、`locales` 和若干 `.dll` 文件一起保留。整个文件夹可放到桌面、U 盘或任意目录直接运行，不需要安装。

文件夹和 exe 文件名使用英文，是为了避免 Windows 10、压缩软件或传输工具在解压时把中文路径显示成乱码。应用窗口标题和界面仍然是中文 `codex_会话管理`。

## 第一次启动：配置公司 NAS

1. 先在 Windows 中连接 `\\192.168.10.99\文件中转站`。本软件不弹出 SMB 密码框，也不保存 NAS 密码。
2. 启动软件后必须先完成 NAS 配置，未配置时不会启动备份代理。
3. 软件固定识别 `codex会话备份`，员工只选择实时目录列表里的部门和姓名，不能输入或选择任意路径。
4. 点击“验证并开始备份”后，会创建或复用当前电脑的设备目录并立即开始首次备份。

目录结构：

```text
codex会话备份\<部门>\<姓名>\devices\<设备>\incremental-backups\
  sessions\
  archived_sessions\
  manifest.json
  status.json
```

正常情况下，新增的完整会话记录会在 30 秒内被发现；软件启动、首次激活、电脑从睡眠中唤醒以及确认 NAS 恢复连接后会立即补扫。每台设备每 24 小时错峰执行一次完整性审计。发现 NAS 会话与本机已验证的完整会话内容不一致时，软件只使用本机已验证内容自动修复；被替换的 NAS 内容先保存在应用自有的 `repair-quarantine\`，保留 30 天，每个会话最多保留 3 份。

状态卡可以显示 NAS 不可用、首次备份、正常、待补传、正在审计、正在修复、审计中断和错误，并记录最近一次成功审计时间。NAS 断开后先在 Windows 中重新连接共享盘，再点“重新检测”。软件不会自动创建假的本地共享路径。更换部门或姓名时点“重新配置”，确认旧身份和新身份后才会生效。

NAS 只保存会话 JSONL、manifest 和状态，不保存账号凭据、账号状态或登录态、本机快照、`auth.json`、`config.toml`、正在使用的 `state_5.sqlite` 或其他 Codex 配置。本机只保存游标和待补传元数据，没有第二份会话正文缓冲；如果 NAS 离线期间源会话也被删除，尚未上传的内容无法恢复。

自动化测试只证明调度、校验和修复流程符合代码约束。Windows 10 与 macOS 实机验收及 24 小时资源测量属于独立的 Task 10 发布门槛，完成前不能把自动化测试结果视为正式发布验收结果。

共享盘当前使用身份 `171`，它不能隔离员工之间的读取权限。软件只能避免选错目录；员工会话的保密隔离必须由 NAS 管理员通过个人账号和目录 ACL 实现。

## SQLite 支持

便携包内置经过固定 SHA3-256 校验的官方 `sqlite3.exe`。恢复、删除和增量找回会通过 SQLite 原生事务更新 `state_5.sqlite`，用户不需要安装 SQLite，也不应单独替换包内文件。

## 已同步的交互

- 单击会话：选中会话并刷新右侧详情。
- 双击会话：打开对话记录窗口。
- 搜索框：输入时做了防抖，避免每个字符都立即重绘列表。
- 右键会话：查看对话、从最近快照恢复、打开文件、显示文件、删除会话。
- 会话列表：支持当前会话和归档会话，支持勾选、全选可见、批量删除。
- 快照恢复：支持手动/系统自动筛选、单个会话恢复、批量恢复选中会话、恢复本快照全部对话和完整恢复。
- 快照类型：手动创建的快照标记为“手动”，删除/恢复前自动创建的保护点标记为“系统自动”。
- 忙碌提示：恢复、删除、创建快照时会在屏幕中间显示进度条和原因说明，文件多时请等待完成。
- 打开时自动找回：默认关闭。用户手动开启后才会检测并提示恢复。
- NAS 备份恢复：可选择当前设备或同一员工名下的旧设备，只恢复当前缺失的会话，不覆盖已存在会话。

## 数据位置

应用读取当前 Windows 用户目录下的数据：

```text
%USERPROFILE%\.codex
%USERPROFILE%\.codex-session-vault\snapshots
```

恢复和删除前会自动创建保护快照。SQLite 索引写入会等待 Codex 的数据库锁；其他 JSONL 和配置文件仍建议在退出 Codex 后恢复。恢复完成后如果 Codex 客户端已经打开，请重启 Codex 后再查看恢复结果。

本机快照仍位于 `%USERPROFILE%\.codex-session-vault\snapshots`。快照用于完整状态回退；公司 NAS 会话备份用于持续保护会话内容，两者不会互相替代。
