# 发布说明

## v1.0.8

首次公开发布版本，包含 macOS App 和 Windows 免安装便携版。

### 下载文件

- `codex_session_keeper_macos_v1.0.8.zip`
- `codex_session_keeper_windows_v1.0.8.zip`

### 主要能力

- 管理当前 Codex 会话和归档会话。
- 创建手动快照，备份 Codex 会话、历史索引和状态库。
- 从快照只恢复对话，保留当前账号、登录态和模型供应商配置。
- 从快照完整恢复 Codex 数据。
- 从快照恢复单个会话或批量恢复选中会话。
- 删除单个或多个会话，并在删除前创建轻量保护快照。
- 删除单个或多个快照。
- 区分手动快照和系统自动保护点，并支持筛选。
- 恢复、删除、创建快照等慢操作显示居中进度提示。
- “打开时自动找回”默认关闭，只有用户手动开启后才会自动检测。

### 使用建议

- 切换 Codex 账号、模型供应商或配置前，先创建手动快照。
- 恢复会话前建议先退出 Codex。
- 恢复完成后如果 Codex 客户端已经打开，请重启 Codex 后再查看结果。
- 日常恢复优先使用“只恢复对话”，避免覆盖当前账号和配置。

### 校验

发布前执行：

```bash
swift build
node --check windows/codex_session_manager_electron/src/main.js
node --check windows/codex_session_manager_electron/src/preload.js
node --check windows/codex_session_manager_electron/src/renderer.js
bash -n scripts/build_app.sh
bash -n scripts/build_windows_exe.sh
./scripts/build_app.sh
./scripts/build_windows_exe.sh
```
