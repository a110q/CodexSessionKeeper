# 发布说明

## v1.0.13

本次修复 Codex 更新后 `state_5.sqlite` 表结构变化导致快照功能失效的问题。

### 下载文件

- `codex_session_keeper_macos_v1.0.13.zip`
- `codex_session_keeper_windows_v1.0.13.zip`

### 变更

- 修复新版 Codex 已移除 `thread_goals`、`stage1_outputs` 等旧表时，创建快照会报 `no such table` 并失败的问题。
- 修复恢复快照、恢复单个会话、删除会话前保护点、删除会话等路径里对旧 SQLite 表结构的硬编码依赖。
- SQLite 清洗、合并、删除逻辑改为先检测表是否存在，再按当前 Codex 实际表结构执行。
- 新增对 `agent_job_items.assigned_thread_id` 的清洗、合并和删除支持，避免新版任务索引残留或恢复遗漏。
- macOS 与 Windows 两端同步兼容新版 Codex 的线程索引结构。

## v1.0.12

本次重点更新 macOS 与 Windows 的界面体验，并同步发布包含最新 UI 的安装包。

### 下载文件

- `codex_session_keeper_macos_v1.0.12.zip`
- `codex_session_keeper_windows_v1.0.12.zip`

### 变更

- Windows 端恢复左侧品牌栏和“当前 Codex 状态”卡片，可直接查看 provider、model、account 和会话数量。
- “打开时自动找回”移动到侧栏设置区，顶部工具栏保留更高频的刷新和打开目录操作。
- macOS 与 Windows 统一为浅渐变、半透明卡片、系统蓝主按钮和更清晰的危险按钮视觉语言。
- Windows 端新增跟随系统的暗色模式。
- 会话列表优化为状态点、标题、相对时间、文件大小和来源信息，缺文件状态更醒目。
- 会话详情页新增前 20 条消息预览，减少频繁打开完整对话弹窗。
- 完整对话窗口调整为用户靠右、助手靠左的消息布局，更适合扫读长对话。
- 保留 `v1.0.11` 的 Windows 快照逐文件容错复制能力。

## v1.0.11

修复 Windows 环境创建快照时，如果某个会话 jsonl 文件被锁定或权限不足，`fs.cpSync` 整目录复制会因为 `EPERM: operation not permitted, lstat ...jsonl` 中断的问题。

### 下载文件

- `codex_session_keeper_macos_v1.0.11.zip`
- `codex_session_keeper_windows_v1.0.11.zip`

### 变更

- Windows 创建快照改为逐文件容错复制，单个不可访问文件会被跳过，不再导致整个快照失败。
- Windows 文件扫描遇到无权限目录时会跳过该目录，避免快照列表或会话列表崩溃。
- 被跳过的文件会写入快照 warning，并在创建成功提示中显示，方便用户定位是哪条会话被锁定。
- 建议 Windows 用户遇到跳过提示时先退出 Codex、杀毒扫描或同步软件，再创建一次补充快照。

## v1.0.10

修复 Windows 环境创建快照时，如果 Codex 的 `state_5.sqlite` 临时不可读、WAL 未合并或数据库文件损坏，会直接报 `database disk image is malformed` 并中断的问题。

### 下载文件

- `codex_session_keeper_macos_v1.0.10.zip`
- `codex_session_keeper_windows_v1.0.10.zip`

### 变更

- Windows 创建手动快照时会先校验 `state_5.sqlite`，不可读时自动降级为文件型快照。
- Windows 创建恢复/删除前保护点时同样支持坏库降级，避免保护点失败导致恢复或删除动作无法继续。
- 降级后的快照仍会包含 `history.jsonl`、`session_index.jsonl`、`sessions` 和 `archived_sessions`，可继续恢复会话文件。
- 创建成功提示会说明 SQLite 索引被跳过，用户可先关闭 Codex 后再创建一次完整索引快照。

### 使用建议

- 如果看到“已降级创建文件型快照”，说明快照已创建成功，并非失败。
- 文件型快照可用于恢复重要会话；如果需要完整 SQLite 线程索引，退出 Codex 后再创建一次手动快照。
- Windows 用户请下载完整 zip 并解压整个文件夹，不要只复制单独 exe。

## v1.0.9

修复快照只包含 `session_index.jsonl`、`sessions`、`archived_sessions`，但没有 `state_5.sqlite` 时，Windows 端无法读取快照内会话的问题。

### 下载文件

- `codex_session_keeper_macos_v1.0.9.zip`
- `codex_session_keeper_windows_v1.0.9.zip`

### 变更

- 快照恢复页改为 SQLite 索引优先，缺失或不可读时自动扫描快照内 jsonl 会话文件。
- 快照内的归档会话同样可通过文件扫描识别和恢复。
- macOS 与 Windows 的快照会话读取逻辑保持一致。
- 空状态提示改为“没有可读取的会话文件或索引”，避免把真实文件存在但索引缺失的情况误报为无会话。

## v1.0.8

首次公开发布版本，包含 macOS App 和 Windows 免安装便携版。

### 下载文件

- `codex_session_keeper_macos_v1.0.8.zip`
- `codex_session_keeper_windows_v1.0.8.zip`

### 主要能力

- 管理当前 Codex 会话和归档会话。
- 创建手动快照，备份 Codex 会话、历史索引和状态库。
- 从快照只恢复对话，保留当前账号、登录态和模型供应商配置。
- 从快照完整恢复 Codex 数据。
- 从快照恢复单个会话或批量恢复选中会话。
- 删除单个或多个会话，并在删除前创建轻量保护快照。
- 删除单个或多个快照。
- 区分手动快照和系统自动保护点，并支持筛选。
- 恢复、删除、创建快照等慢操作显示居中进度提示。
- “打开时自动找回”默认关闭，只有用户手动开启后才会自动检测。

### 使用建议

- 切换 Codex 账号、模型供应商或配置前，先创建手动快照。
- 恢复会话前建议先退出 Codex。
- 恢复完成后如果 Codex 客户端已经打开，请重启 Codex 后再查看结果。
- 日常恢复优先使用“只恢复对话”，避免覆盖当前账号和配置。

### 校验

发布前执行：

```bash
swift build
node --check windows/codex_session_manager_electron/src/main.js
node --check windows/codex_session_manager_electron/src/preload.js
node --check windows/codex_session_manager_electron/src/renderer.js
bash -n scripts/build_app.sh
bash -n scripts/build_windows_exe.sh
./scripts/build_app.sh
./scripts/build_windows_exe.sh
```
